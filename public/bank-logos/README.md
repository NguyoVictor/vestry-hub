## Usage

These logos are used in the PaymentChannelSetup component when users select their bank for payment channel registration.

## Format

All logos are SVG format (32x32px) with consistent styling:
- Rounded corners (6px radius)
- Brand-appropriate colors
- White text on colored background
- Fallback to Building2 icon if logo fails to load
